# Sri Lanka general statutory pack

- **Covers:** VAT for registered businesses (standard-rated, not-recoverable standard-rated, zero-rated, exempt) and the Social Security Contribution Levy for services, wholesale and retail, manufacture and registered-distributor businesses. Rules apply from 2024-01-01. Returns are management mappings, not the IRD forms. Sources were read on the IRD website on 2026-11-14.
- **Does not cover:** withholding tax, income tax, payroll taxes (APIT, EPF, ETF), customs, VAT on financial services, importer SSCL, reverse charge and digital-services VAT for non-residents, special schemes.
- **Open warnings and why they are accepted:** none from the checker. Author decisions still to confirm: line rounding (not confirmed against IRD practice), and the VAT return due date entered as the last day of the following month.
- **Capability requests:** see capability-requests.md

Author details in `pack.yaml` use a test membership number.
